# climat-cultures

Application web qui croise projections climatiques (Open-Meteo) et seuils agronomiques pour aider agriculteurs et collectivités à anticiper quelles cultures resteront viables dans une commune donnée, à l'horizon 2050.

Projet réalisé dans le cadre de la SAÉ 3.01 -BUT Informatique, IUT Créteil-Vitry (UPEC).
